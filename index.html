  • 씬 전환 시 로비 유지 문제 → 네트워크 로직을 NetworkBridge로 분리해 해결
  • 포탄 반사 시 충돌 시점 속도 변형 문제 → FixedUpdate에서 이전 프레임 속도를 보존하는 구조로 해결
  • Unity Profiler로 프레임마다 UI 갱신 패킷 과다 전송을 원인으로 특정 → 임계값·변화 시에만 패킷 전송하도록 수정해 프레임 드롭 해결

  • WebGL에서 서버 소켓 불가 문제 → 싱글플레이도 Relay Allocation을 생성해 Host로 우회 해결
